How to use

  • Type lyrics directly into the table rows, or upload a .json / .txt file.
  • Use / within a row to add line breaks inside the sticker (e.g. line one / line two).
  • Click a row to select it, then hit Preview to see how it looks.
  • Adjust the preset (aspect ratio), background gradient, and fill width slider to style the output.
  • Download PNG saves the selected row. Download All saves every row as a ZIP.
  • Save lyric data as JSON exports your current table data so you can reload it later.

JSON format: {"name": "line 1\nline 2", ...} — each key becomes the output filename.

TXT format: one record per line, / = newline within the image.
